# C01 — Automation foundation

Result: passed 19 focused contract tests, zero skips, on Ubuntu 20.04 WSL2.
This card uses an explicitly labelled contract subprocess, not native workflow
acceptance. C02 owns attachment of the real runtime proven by C00.

Delivered `dev/emu`; strict versioned action/ack/scenario/observation/capability/
error/manifest schemas; a loopback session server; ordered input acknowledgment;
isolated session/data directories and explicit stop; deadline-based scenario
assertions; structured failure bundles; content-based source/artifact verification;
and recipe replay in a fresh session. See `docs/architecture/automation-protocol.md`.

Validation:

```sh
./dev/emu test --suite contracts --require-all
./dev/emu run fixtures/scenarios/contract-counter.json
./dev/emu verify-evidence artifacts/runs/9e2a08ad68374270a8677726127b3d79/manifest.json
./dev/emu replay artifacts/runs/9e2a08ad68374270a8677726127b3d79/manifest.json
```

The suite took 28.101 seconds. Log: `artifacts/c01-contracts.log`; sample command
output: `artifacts/c01-sample.json`. The verified sample run is
`9e2a08ad68374270a8677726127b3d79`; the independent replay run is
`6912211207de434795b8c581c66726c5`. Their schema-checked manifests retain actual
source-file identities, test count, scenario, input/ack trace, observations and
artifact hashes. Compact retained evidence is `C01-evidence.json`.

Deliberate failure cases rejected: invalid coordinates/types/fields, unknown
schema constraints, wrong order, duplicate action identity, an impossible
assertion, observation timeout, backend crash/stall, empty scenarios/test
collection, missing or changed artifacts, stale source, artifact path escape,
fixture-only evidence labelled E, missing release inventory, unknown suites,
and JSON property ordering that could otherwise bypass a wait. CLI failures
return nonzero and write failure evidence when a scenario run has begun.

`release-check` enforces preliminary family/scenario/generic coverage but remains
incapable of certifying release until owning cards attach review records and
A20/A21-specific evidence semantics. It fails explicitly even if preliminary
coverage is supplied. This is deliberate staged implementation, not a waiver of
release acceptance. Native backend requests also fail explicitly until C02.
