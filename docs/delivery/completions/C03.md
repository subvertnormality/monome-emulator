# C03 — Native grid conformance and Mosaic navigation

Passed on Ubuntu 20.04 WSL2. The virtual 128 grid now supports single/bulk/relative
LED writes, refresh, levels 0–15, all four rotations, intensity, separate held keys
and native disconnect/reconnect. Physical tilt is an explicit unsupported Lua
error. See `docs/architecture/grid-contract.md` for coordinate/lifecycle semantics.

Validation:

```sh
./dev/emu build
python3 tests/grid_native.py
./dev/emu test --suite contracts --require-all
```

The native package passed six checks. Its main conformance check exercises down/up
on all 128 cells (256 native transitions), every absolute brightness level,
nonuniform bulk updates, staging until refresh, relative upper/lower clamps,
all rotations, intensity extremes, two simultaneous holds, duplicate rejection,
release-all and disconnect/reconnect. It separately verifies zero-based transport
coordinates and the resulting one-based runtime callbacks via literal MIDI bytes.

Actual Mosaic navigated channel, scale, trig, note, velocity and song pages using
grid input, with raw menu LED expectations derived from its documented controls
and pinned button/page definitions. Navigation still worked after reconnect.
No application state was mutated or inspected to select pages. Disposable probe
faults swapping coordinates and dropping releases were rejected by the same
callback/output assertions. Two additional schema-checked native/API scenarios
provide repeatable I/E manifests. The protocol/evidence suite passed all 21 tests,
zero skips (49.972 seconds while the native package also ran).
