# C04 — Native browser controls and rendering

Passed: 22 automated browser checks across four fresh native sessions, plus all
22 protocol/evidence/client contracts, zero skips (90.212 seconds). Native services
ran on Ubuntu 20.04 WSL2; Windows Chromium headless shell 151.0.7922.34 and
Playwright 1.62.1 drove real DOM, pointer and keyboard interactions.

Reproduction commands, from the repository root:

```powershell
.\tests\browser_package.ps1
wsl -d ubuntu-20.04 -- python3 dev/emu test --suite contracts --require-all
```

Both independently named generic apps ran with Mosaic and its optional fixtures
hidden from their native runtime mount namespaces. Seven checks per generic app
cover actual Cairo pixels, browser/API input equivalence, shift, native menu,
simultaneous holds, focus loss, raw LED rendering, stale-renderer rejection and
offline browser disconnect. The first probe independently checks all 16 screen
levels. Native wire expectations use literal coordinate/key/delta tables, with
MIDI callbacks as additional observable consequences.

Mosaic passed six native grid page/tooltip transitions plus full native-to-browser
pixel comparison. A separate faulty script passed the expected-error test: real
K2 input causes a Lua exception, visible runtime error and failed runtime request.
This is browser error observability evidence, not a successful musical workflow.

Initial evidence packaging correctly failed because exceptional actions lacked
an API trace. The server now records failed requests and their structured errors,
without a successful acknowledgement. A contract regression checks this. Final
unique session bundles all verify against their loaded emulator/app/runtime
identities, artifact hashes and clean matron/crone/JACK exits. The complete package
was rerun after that fix. Earlier failed/debug bundles are retained but excluded.

`C04-evidence.json` records the four manifest paths/digests and counts. Each run
retains action and native traces, raw frame, browser screenshot, observations,
results and service logs. The source digest binds all implementation/test/UI files;
documentation-only recording does not alter that digest.

Changes: `ui/`, authenticated static serving and client leases, native pixels and
menu diagnostics, action ownership/failure trace, browser evidence schema/verifier,
and browser fixtures/tests. See `docs/architecture/browser-contract.md`.

This closes C04 control/rendering acceptance. C05 owns complete MIDI ports/capture,
C06 edit/play/save and P1; C12 owns complete A19 edits during playback and render
latency acceptance. No manual testing or real hardware was required. M1 is not yet
passed and this is not a full emulator release.
