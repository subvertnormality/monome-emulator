# Stage 2 admission: sampler workflows and virtual arc

2026-09-08. Implementation `abef865`, review fixes `3b94aed` and `dc4f086`.
The tested softcut/sampler and virtual arc subset is admitted for opt-in use on
this Ubuntu 20.04 WSL2 host. This closes A02/A03/P03 within their documented
acceptance scope. The default runtime is preserved.

Use `.runtime/arc-tools-01/installation.json` inside the retained audio-monitor
worktree. From main, pass:

```sh
./dev/emu start --experimental-install .runtime/worktrees/audio-monitor/.runtime/arc-tools-01/installation.json --script /path/to/code/app/app.lua --code-root /path/to/code --no-crow --arc
```

Arc is optional; omit `--arc` when absent. `--no-crow` selects actual device
absence and is required for the tested cheat codes baseline because attached
Crow ii-module reads remain unsupported. Import disposable samples with
`--audio-file` or `--audio-directory`. For slow synchronous operations use
`--input-timeout 10`, which bounds the entire action including implicit releases.
A native timeout is a sticky failure: stop the session and start a fresh one.

The official pinned norns runtime is retained. New patches are locally authored
read-duration bounds and a virtual arc transport; official softcut and arc Lua
behavior remain in the runtime. Sources, patch rationale/removal conditions and
commands are indexed in [the candidate record](A02-A03-P03-candidate.md).
