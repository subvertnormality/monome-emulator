# C06 — Four-step Mosaic vertical slice completed

M1 passed on Ubuntu 20.04 WSL2. P1's recovered initial critique and single focused
follow-up found no remaining substantive blockers after the recorded fixes.

The actual unmodified Mosaic application creates a four-step pattern through grid
input, sets C4/D4/E4/F4 and velocities 127/117/107/97, assigns it to a channel and
sets a four-step loop. Literal native MIDI expectations cover two initial loops.
An E4→G4 edit during playback is checked against every following captured note,
preserving order with the observed cycle phase; the gate cannot wait several
cycles and ignore an incorrectly delayed edit. Stop must drain counted notes.

The native parameter menu opens Mosaic's Save trigger and textentry confirms
`new`. Native autosave runs on its actual 60-second timer. A fresh runtime copies
the owned saved data and boots through the existing-autosave path. Before explicit
Load, controls alter a note again, so leaving the autosaved live state in place
cannot pass. The actual file dialog loads `new.ptn`; two loops must reproduce the
saved edited sequence. The saved `.ptn`/`.pset` files and input/output evidence are
retained. No application globals or parameter actions are mutated by the harness.

API and browser use the same Python recipe. The Windows browser driver operates
real keyboard, encoder buttons and multi-touch events. Each native key/grid trace
must match its recipe exactly; consecutive encoder ticks in the same direction
are summed to compare one API delta with multiple browser button presses. Native
MIDI outcomes use the same literal tables. Browser pixels are compared with the
actual Cairo framebuffer and screenshots are retained without human judgement.
An independent content oracle renders literal Note Masks and Device Config titles,
six tab indicators and the Mosaic mark from documented source layout coordinates.
The first ten pixel rows must match exactly (excluding alpha only). It reuses the
pinned font and Cairo, never Mosaic's draw code or an output-captured golden.
It also rejects a blank-frame fault. This supplements MIDI and renderer assertions.
