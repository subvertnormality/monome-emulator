# C02 — Official native sessions and application loading

Passed on the existing Ubuntu 20.04 WSL2 distribution. M0 is complete; browser,
full device conformance and complete Mosaic workflow acceptance remain open.

The generic CLI fetches and builds pinned official norns/libmonome separately
from optional application fixtures. Each real matron/crone/SC/JACK session has
its own dust/data root, ports, JACK name and native events. A fresh build applies
all seven recorded patches. Binary and interpreted-source hashes reject changed
installations. Generic app source identities include dirty content and sibling
include libraries. No core package imports or dispatches on Mosaic or its mods.

Validation, with zero skips:

```sh
./dev/emu fetch --locked
./dev/emu build
./dev/emu fixtures fetch mosaic --locked
./dev/emu test --suite contracts --require-all
python3 tests/native_loader.py
# root, private mount/network namespace:
unshare --mount --net --fork sh tests/isolated_generic.sh
```

The contract package passed 21 tests in 29.463 seconds. The native loader package
passed nine checks: two differently named generic scripts; base Mosaic boot;
matrix/toolkit-profile Mosaic boot and actual hook execution; intentional init,
coroutine and caught-hook errors producing structured nonzero failure manifests;
two simultaneous isolated native sessions with real controls/MIDI/frame changes;
and absence of owned processes/HOME aliases after cleanup. Both generic scenarios
also passed with `upstream/` and `.runtime/fixtures/` hidden and no network route.

Mosaic retained `testing = false`, its actual init, scheduler and redraw clocks,
native params, n.b. and grid attachment. Its first script frame was captured after
a native screen-worker barrier. Base boot had 3,336 params and ten live clock
coroutines. Mod boot executed toolkit pre-init and matrix depth/read hooks through
the actual mod lifecycle. This proves activation, not the C09 modulation workflow.
Mosaic's initial autosave metro is stopped until later editing; readiness does not
invent a requirement that it already be running.

Fixes driven by failed probes: a short isolated HOME alias avoids a Lua-pattern
path bug in n.b. without upstream application edits; explicit keyboard config
eliminates missing-config fallback; raw encoder sensitivity is declared by the
probe; shutdown uses native/OSC quit before JACK. gdb identified crone's detached
buffer worker accessing memory during destruction; patch 0007 joins workers and
stops polls. Matron/crone/JACK now exit zero; sclang receives the expected SIGTERM
after scsynth quits. Unexpected shutdown codes fail a run. A one-time utility
recovered only recorded inactive emulator JACK registrations through JACK itself.
